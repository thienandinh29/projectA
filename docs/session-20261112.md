1. Start in order from the main folder: `docker compose up -d redpanda redis`, then
   `docker compose up -d lakehouse-writer console`, then `docker compose --profile workers up -d worker-rss worker-gdelt`.
   Run `scripts.collection_health` and expect a gap in the record for the whole pause.
2. Before any final-study collection: move to the server ([cloud-collection-server.md](cloud-collection-server.md)),
   capture a new baseline with `scripts/capture_baseline.py`, and freeze metric conventions.
3. Postponed until after Dec 20: more labels, a second annotator, sample size, GDELT and Investing.com
   decisions, final collection, and the paper.
